We need to calculate the residence-time matrix to be used for simulating an epidemic that allows movement between patches. To do that, we have mobile GPS data for ~30k individuals, that we will be using to form a distribution for time spent in each patch (AGEB) of Hermosillo. We will be using python to perform this calculation. The idea is inspired from using Brownian Bridge Movement Models to model the movement of animals in nature.

* Libraries
Since we are working with geospatial data, we will be using the [[https://geopandas.org/][geopandas]] library, which is built on the pandas library, along with other standard libraries like numpy, scipy, and matplotlib. We will also use scipy to perform an optimization problem to estimate one of the parameters \(\sigma_m\).

** TODO Determining \(\sigma_m\)
\(\sigma_m\) is a parameter that we need to estimate for each individual by using the GPS data. We can do this by optimizing on a loglikelihood function.

#+begin_src jupyter-python :results raw drawer
def L_mod(gdf_ind, sigma_m, delta_z):
    result = 0
    for i in range(0, len(gdf_ind)-2, 2):
        start_point = gdf_ind.iloc[i]
        mid_point = gdf_ind.iloc[i+1]
        end_point = gdf_ind.iloc[i+2]
        T_i = (end_point["timestamp"] - start_point["timestamp"]).total_seconds()
        alpha = (mid_point["timestamp"] - start_point["timestamp"]).total_seconds()/T_i
        mu_tx = start_point["geometry"].x + alpha*(end_point["geometry"].x - start_point["geometry"].x)
        mu_ty = start_point["geometry"].y + alpha*(end_point["geometry"].y - start_point["geometry"].y)
        sigma_t = np.sqrt(T_i * alpha * (1 - alpha) * sigma_m**2
                          + ((1 - alpha)**2 + alpha**2) * delta_z**2)
        result += 2 * np.log(sigma_t) + (((mid_point["geometry"].x - mu_tx)**2 + (mid_point["geometry"].y - mu_ty)**2)/(2 * sigma_t**2))

    return result
#+end_src

#+RESULTS:

We will now use the =L_mod= function to perform the optimization to calculate =sigma_m=.

#+begin_src jupyter-python :results raw drawer
from scipy.optimize import minimize_scalar

def calculate_sigma_m(gdf_ind, delta_z):
    res = minimize_scalar(lambda sigma_m: L_mod(gdf_ind, sigma_m, delta_z))
    sigma_m = res.x
    return sigma_m
#+end_src

** Calculate \(h_z\)
Now that we have the basics in place, we can calculate the values of \(h_z\) for various points throught Hermosillo using Monte Carlo Integration.

#+name: gaussian_pdf
#+caption: Calculate the values of a gaussian pdf with mu and sigma, at x
#+begin_src jupyter-python :results raw drawer
def norm_pdf(x, mu, sigma):
    mu, sigma = mu.reshape(-1, 1), sigma.reshape(-1, 1)
    x = x.reshape(-1, 1)
    variance = sigma**2
    numerator = x - mu
    denominator = 2 * variance
    pdf = ((1/(np.sqrt(2 * np.pi) * sigma)) * np.exp(-(numerator**2) / denominator))
    return pdf
#+end_src

#+RESULTS: gaussian_pdf

#+name: h_z
#+begin_src jupyter-python :results raw drawer
rng = np.random.default_rng()
def h_z(a, b, T_i, x, y, sigma_m2, delta_a, delta_b, indicator, n_time_samples=1000):
    mc_sum = np.zeros(x.shape)
    t = rng.uniform(0, T_i, size=n_time_samples)
    alpha = t/T_i
    mu_x = a.x + alpha * (b.x - a.x)
    mu_y = a.y + alpha * (b.y - a.y)
    sigma = np.sqrt(t * (1 - alpha) * sigma_m2
                    + (1 - alpha)**2 * (delta_a**2)
                    + (alpha**2) * (delta_b**2))
    pdf_x = norm_pdf(x, mu_x, sigma)
    pdf_y = norm_pdf(y, mu_y, sigma)
    mc_sum += indicator * pdf_x * pdf_y

    return mc_sum
#+end_src

#+RESULTS: h_z

Using the =h_z= function, we can calculate the probability of a given region (AGEB).

#+name: prob_region
#+begin_src jupyter-python :results raw drawer
def prob_region(data, cve_ageb, gdf_ind, sigma_m, delta_z, M):
    N = len(gdf_ind)
    polygon = data.loc[data["CVE_AGEB"] == cve_ageb, "geometry"]
    limits = polygon.bounds.iloc[0]
    rx = rng.uniform(limits["minx"], limits["maxx"], M).reshape(-1, 1)
    ry = rng.uniform(limits["miny"], limits["maxy"], M).reshape(-1, 1)
    points = gpd.GeoSeries(gpd.points_from_xy(rx, ry, crs="EPSG:3857"))
    indicator = points.within(polygon.iloc[0]).to_numpy().reshape(-1, 1)
    T_total = (gdf_ind["timestamp"].max() - gdf_ind["timestamp"].min()).total_seconds()
    tot = 0
    for i in range(N-1):
        start_point = gdf_ind.iloc[i]
        end_point = gdf_ind.iloc[i+1]
        T_i = (end_point["timestamp"] - start_point["timestamp"]).total_seconds()
        a, b = start_point["geometry"], end_point["geometry"]
        prob = h_z(a, b, T_i, rx, ry, sigma_m**2, delta_z, delta_z, indicator, n_time_samples=M)
        accum = prob.sum()
        tot += (limits["maxx"] - limits["minx"]) * (limits["maxy"] - limits["miny"]) * accum * (T_i/M)

    return tot/T_total
#+end_src

    indicator = points.within(polygon.iloc[0]).to_numpy().reshape(-1, 1)
    T_total = (gdf_ind["timestamp"].max() - gdf_ind["timestamp"].min()).total_seconds()
    tot = 0
    accum_values = []
    gdf_ind["T_i"] = (gdf_ind["next_time"] - gdf_ind["timestamp"]).dt.total_seconds()
    gdf_ind["hz"] = gdf_ind.apply(lambda row: h_z(row["geometry"], row["next_point"],
