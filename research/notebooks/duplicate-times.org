#+title: Investigation of Duplicate Timestamps
#+date: 2021:06:07
#+property: header-args :session duplicate :exports both

The source data contain records with the same device identifier and timestamp,
sometimes at different locations. The following queries examine duplicate
timestamps in records from <2020-01-01> through <2020-12-31>.

* Total duplicate timestamps
Duplicate records are counted within each device so that simultaneous records
from different devices are not conflated. The query reports both collected and
distinct timestamps for every device.

#+begin_example sql
SELECT 
  count(id_adv) as total_ids,
  sum(distinct_timestamps) as total_distinct_timestamps,
  sum(collected_timestamps) as total_collected_timestamps,
FROM
  (SELECT
    id_adv,
    count(distinct(timestamp)) as distinct_timestamps,
    count(timestamp) as collected_timestamps
  FROM
    `movilidadcovid.Movilidad.Hermosillo`
  WHERE
    DATE(timestamp) BETWEEN "2020-01-01"
    AND "2020-12-31"
  GROUP BY id_adv);
#+end_example

The difference between collected and distinct timestamps is *935,988*. This is
the number of excess device-timestamp records in the selected date range.

| Total IDs | Total Distinct Timestamps | Total Collected Timestamps |

* Per-device duplicate timestamps
The per-device counts show whether duplicate records are broadly distributed
or concentrated among a smaller set of devices.

#+begin_src sql
SELECT
    id_adv,
    count(distinct(timestamp)) as distinct_timestamps,
    count(timestamp) as collected_timestamps
  FROM
    `movilidadcovid.Movilidad.Hermosillo`
  WHERE
    DATE(timestamp) BETWEEN "2020-01-01"
    AND "2020-12-31"
  GROUP BY id_adv;
#+end_src

The query result is read from the access-controlled data directory.
